# Selected reference results

`selected/` contains byte-preserved tables from the frozen final evidence:

| File | Interpretation |
|---|---|
| `primary_model_metrics.csv` | Full final 23-feature model performance |
| `model_comparison_fdr.csv` | Paired model contrasts and declared multiplicity correction |
| `specificity_bh6.csv` | Six raw-target specificity tests with 1,000 controls per module |
| `residual_specificity_bh6.csv` | Separate six-test family after technical adjustment |
| `nav6_vs_nav7.csv` | Gene-definition sensitivity; distinct targets |
| `technical_target_performance.csv` | Library count and detected-gene prediction |
| `target_correlations*.csv` | Raw, subclass-centered, and technically adjusted target correlations |
| `matching_diagnostics.csv` | Expression/detection matching quality summary |

Raw specificity rejects the matched-control null for GABAA and iGluR after
six-test BH. Kv is less predictable than many matched sets despite positive
R². Technical adjustment is a separate analysis and does not change the raw
family's interpretation. Split-half consistency describes internal consistency,
not test-retest reliability or a formal prediction ceiling.

`manifests/selected_artifact_checksums.sha256` verifies the packaged reference
tables. `expected_hashes.json` retains original full-analysis digest contracts;
those large artifacts are regenerated or supplied locally, not included in Git.

Full OOF predictions, fitted models, complete control partitions, and caches
are generated by the pipeline. They are excluded from version control to keep
the repository practical to clone. New-run outputs do not replace `selected/`.
